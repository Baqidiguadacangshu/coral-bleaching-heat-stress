## Tools
I used ChatGPT to help me understand Python code, develop the visualisation, and revise the animation. I described the visual results I wanted, tested the code in VS Code, and gave feedback based on what appeared on screen. I used Python to process the NOAA data and create the animation, and GitHub to save the development of the project.
## Kept
I kept the idea of using the NOAA heat stress data to control the coral's colour and form. As the data changes, the coral becomes paler and its shape changes. I liked this because the visual change connects directly to coral bleaching while keeping the coral as the main focus of the work.

I also kept the flowing strands and particles because they made the coral feel more organic and helped turn the numerical data into a visual experience rather than a conventional chart.
## Rejected
I rejected some early versions because the generated shapes did not look enough like coral and the movement felt too artificial. I kept asking for changes to the shape, colour and movement instead of accepting the first working result.

Later, I considered adding a more obvious line chart to make the data easier to read, but I rejected it because it made the work feel too much like a conventional data chart and distracted from the coral. I decided to keep the year, value, colour legend and simple timeline instead.

AI helped write much of the plotting code, but working code was not always the right visual result. My main corrections were deciding how the data should affect the coral and repeatedly adjusting the generated code until the visual result matched my intention.
